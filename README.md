# Catatan OverTheWire Bandit (Level 0-5)

Berikut adalah 5 perintah yang saya pelajari:
1. `ssh` : Untuk masuk (login) ke server jarak jauh.
2. `ls -la` : Untuk melihat semua file, termasuk file tersembunyi (yang diawali titik).
3. `cat` : Untuk membaca isi file teks.
4. `find` : Untuk mencari file berdasarkan kriteria (seperti ukuran atau pemilik).
5. `file` : Untuk mengecek jenis tipe sebuah file (teks, binary, dll).
